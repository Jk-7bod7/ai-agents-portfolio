# Manual Test Cases

All examples are synthetic and use `example.test` domains.

## Hot Lead

Expected score: `100`\
Expected classification: `Hot Lead`

```json
{
  "name": "Sara Hassan",
  "company": "Demo Startup",
  "email": "sara@example.test",
  "budget": 5000,
  "companySize": 25,
  "problem": "We need to automate lead follow-up",
  "timeline": "This month"
}
```

## Warm or Cold Lead

Change the values in `Edit Fields`, execute the workflow, and inspect the
`Code in JavaScript` output. The score determines the classification:

- 75+: Hot Lead
- 50-74: Warm Lead
- 1-49: Cold Lead

## Needs Review

Remove `problem` or another required field. The Code node should return
`qualificationScore: 0`, `classification: Needs Review`, and list the missing
field in `reasons`.

## AI output

Open `Basic LLM Chain` after execution. Its Output panel should contain a
summary and a recommended next action generated by the local Ollama model.
